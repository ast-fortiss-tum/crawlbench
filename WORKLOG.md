## 2026-11-18 Mutation testing: investigation of multilayer-mt (https://github.com/ast-fortiss-tum/multilayer-mt)
- Cloned to the scratchpad only (`.../scratchpad/mlmt/repo`), not in the repo. TypeScript/Node tool (Node >= 18), runtime black-box mutation of *Playwright* suites on 3 layers (DOM 32 thesis ops, network 11, test-script 8; library of 251 more). App source and tests are not modified; the app must be running. Built with `npm ci && npm run build` (Node 20 from ~/tools/node). Playwright 1.63 does not support Ubuntu 20.04: Chromium installs with `PLAYWRIGHT_HOST_PLATFORM_OVERRIDE=ubuntu22.04-x64 npx playwright install chromium` and runs (Chrome 153, no missing libs).
- Demo (examples/todo-app, 8 tests, `run --max-mutants 20 --workers 2`): 20 mutants, 6 killed / 11 survived / 3 skipped, score 35.3%, 84 s wall, 4.9 s per executed mutant.
- Gap for CrawlBench: DANTE suites are Java/JUnit/Selenium with NO assertions (only get/clear/sendKeys/click + sleeps; a test fails only when an action throws). MLMT needs Playwright specs. Options: translate `selenium-actions-*` (paths separated by "----") into one Playwright spec per path, and decide an oracle. MLMT computes PWE from each suite's own trace, so mutant sets differ per suite; PLAN.md requires the same mutants per app across configs, which needs a fixed mutant set (CLI has `--max-mutants` seeded sampling and `--reuse-trace`, but no obvious load-mutants-from-file).
